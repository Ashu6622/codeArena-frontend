# CodeArena Frontend

CodeArena V1 frontend, built with Next.js App Router and TypeScript.

The landing page includes an interactive sample playground and a searchable starter problem collection.

```bash
npm install
npm run dev
```

Open http://localhost:3001.

Checks: `npm run quality`, `npm run build`, and `npm test` (requires Google Chrome).

See [Landing Page](docs/frontend/landing-page.md) for behavior, scope, and verification.

See [Frontend Structure](docs/frontend/frontend-structure.md) for folder responsibilities and documentation conventions.
